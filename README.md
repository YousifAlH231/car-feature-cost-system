# Car Feature Cost Management System

A university C++ project that demonstrates object-oriented programming concepts through a car feature cost calculation system.

## Overview

The program calculates the total cost of a car based on different feature categories, including:

* Safety features
* Luxury features
* AI features
* Executive features

Each category extends the previous one using inheritance.

## Concepts Used

* Object-Oriented Programming
* Inheritance
* Polymorphism
* Abstract Classes
* Virtual Functions
* Function Overriding
* Constructors
* Base-Class Pointers

## Classes

The project contains the following classes:

* `Car`
* `Safety`
* `Luxury`
* `AI`
* `Executive`

## Files

* `Car.h` – Class declarations
* `Car.cpp` – Class function implementations
* `main.cpp` – Program execution and object testing

## Example

The program creates different car objects and calculates their costs based on the selected features.

It also uses a `Car` pointer array to demonstrate polymorphism and dynamic binding.

## Language

C++
